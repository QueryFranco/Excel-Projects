## 🔍 Proyectos

### [📊 Proyecto 1: Dashboard de Salarios](Proyecto_1-Salary_Dashboard/)

Dashboard interactivo que permite explorar salarios de empleos en ciencia de datos. Incluye gráficos de barras, mapas geográficos, formularios con validación de datos y fórmulas数组 avanzadas.

| Habilidades Excel | Descripción |
|---|---|
| 📉 Charts | Gráficos de barras y mapas |
| 🧮 Fórmulas y Funciones | MEDIANA, FILTRAR, BUSCARV |
| ❎ Validación de Datos | Listas desplegables interactivas |

---

### [📊 Proyecto 2: Análisis del Mercado Laboral](Proyecto_2-Job_Market_Analysis/)

Análisis completo del mercado de trabajo en ciencia de datos respondiendo preguntas clave sobre salarios, habilidades demandadas y tendencias geográficas.

| Habilidades Excel | Descripción |
|---|---|
| 📊 Tablas Dinámicas | Resúmenes y agrupaciones |
| 🧮 DAX | Expresiones de análisis de datos |
| 🔍 Power Query | Extracción y transformación ETL |
| 💪 Power Pivot | Modelos de datos relacionales |
| 📈 Gráficos Avanzados | Gráficos combinados y pivot charts |

## 🚀 Cómo Usar

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/QueryFranco/Excel-Projects.git
   ```

2. **Abre los archivos en Excel**
   - Navega a la carpeta del proyecto que te interese
   - Abre el archivo `.xlsx` con Microsoft Excel

3. **Explora el Dashboard**
   - Usa los filtros y validación de datos para interactuar
   - Modifica los parámetros para ver diferentes resultados
